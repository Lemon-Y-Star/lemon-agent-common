# 常见问题排查

问：发起对话后提示"尚未配置启用的模型连接"？答：在「模型连接」页添加个人连接（OpenAI 兼容端点 + API 密钥 + 模型名），端点主机必须在平台白名单内，保存后确认状态为启用。密钥加密存储，编辑时留空表示保留原密钥。

问：提示"该会话已有正在执行的运行"？答：同一会话同时只允许一个活跃运行（运行中或待审批），等待完成、取消或换一个会话。会话互斥由服务端保证，错误码 SESSION_BUSY。

问：流式输出中断了怎么办？答：前端自动以 afterEventId 重连补齐，无需手动操作。若长时间显示"连接已断开"，检查后端服务是否存活；刷新页面可从数据库恢复全部消息与运行状态。

问：创建工单没有立即执行？答：这是预期行为。创建工单是高风险写操作，会挂起等待审批，页面上会出现审批卡片，批准后才会真正写入工单表；五分钟不处理将自动拒绝。

问：如何切换使用的模型？答：模型连接里配置的模型列表，运行时取最新启用的连接的第一个模型。多模型路由与节点级选择属于后续版本的 Agent 搭建能力。

问：改密码后为什么要重新登录？答：改密成功后当前账号的全部会话令牌立即吊销（安全设计），返回登录页用新密码登录即可。
